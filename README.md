# 归庭 小说与游戏美术资料

**资料版本：v12 · 正文内容版本：v09 · 更新日期：2026-09-10**

《归庭》为游戏提供剧情背景与美术参考，采用架空欧洲魔法世界风格。仓库现行资料包含正文、22张剧情插图、31张物品装备概念图及4张环境概念图；不包含游戏程序或外部参考图鉴。

从 [正文](docs/归庭_游戏剧情正文.docx)、[插图位置索引](art/插图位置索引.md) 和 [美术画廊](art/预览.html) 开始查看。

## 文件结构

|目录或文件|用途|
|---|---|
|docs/|现行正文使用固定文件名；同目录中的旧版文档作为历史遗留保留。|
|art/story/|22张剧情插图，对应DOCX中的插图编号及分支结局。|
|art/items/|31张武器、防具、医疗装备、饰品、药剂与日用品概念图。|
|art/maps/|4张世界、城镇、聚落与乡村环境概念图。|
|art/v*/|历史版本目录及其原有文件，完整保留；开发使用以上现行分类目录。|
|art/素材清单.json|35张游戏概念图的编号、类别、档次、路径、尺寸与文件校验信息。剧情图另见插图位置索引。|
|art/素材索引.md|装备分档说明、用途及全部游戏概念图入口。|
|art/预览.html|离线画廊，支持三档装备对照、小图标、剪影及深浅背景。|
|art/生成提示词.md|美术生成过程的提示词记录；现行图片以清单为准。|
|history/|历次修订记录及本次目录迁移说明。历史记录中的旧路径对应当时版本。|
|scripts/|文档文字提取工具。|
|VERSION|当前资料版本号，与本README保持一致。|

## 游戏开发使用

DOCX为剧情评审文档，Markdown由DOCX自动提取，便于查看文字差异。插图标识中的路径均相对于仓库根目录；变更图片路径时，同步更新DOCX、文字快照、插图索引和交付包。

T1、T2、T3表示美术进阶档次，实际等级、数值和装备槽位由游戏开发确定。伊澜使用冰系魔法，陶恩负责治疗辅助，塞维与赫铎使用物理武器。新增纹章、势力标识及专属设定先由作者确认。

## 版本管理

现行文件使用固定目录与文件名。art/与docs/下已有的历史版本目录及旧文件继续保留，不删除；今后更新现行资料时不再新增版本子目录。旧正文、旧图片及候选图也可通过Git历史或已有标签查阅。v12是本次资料结构整理版本，正文内容版本仍为v09。

历史创作资料从v02归档稿开始，不等于全部聊天记录。目录整理前的完整状态保存在提交 `ee9dc10`。本次已恢复该提交中的art/历史版本目录和docs/旧文档，此前标签保持原样。现行入口以本README及art/素材清单.json为准。

```bash
git lfs install
git lfs pull
python3 scripts/docx_to_md.py docs/归庭_游戏剧情正文.docx docs/归庭_游戏剧情正文.md
git log --oneline --decorate
```
